# 04: Sorting and category management

**What to build:** Give the user control over how todos are ordered and let them create and use custom categories so the planner matches their preferred organization.

**Blocked by:** 01: Todo storage foundation, 02: Add todo and list view, 03: Complete, edit, and delete todo flow

**Status:** ready-for-agent

- [ ] Support multiple sorting modes including newest first, oldest first, alphabetical order, and completed items last.
- [ ] Preserve the selected sort order while the user interacts with the list.
- [ ] Include default categories and allow the user to add custom categories.
- [ ] Ensure category selection and editing remain consistent across the app.
